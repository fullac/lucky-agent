HTTP API 说明

这是 lh serve 对外的产品接口。默认地址是 http://127.0.0.1:9090，应用路由都在 /api/v1。路由注册在 luckyagent-api，行为在 luckyagent-app。本页列出当前已注册的方法和稳定字段；字段细节以仓库 docs/API.md 和对应 handler 为准。

适用范围

项目约定
进程lh serve。根路径 GET / 返回简短路由摘要。
内容类型JSON 请求默认 2 MiB，必须是一个完整 JSON 值。显式不支持的 Content-Type 返回 415。省略该头的旧客户端仍可使用。
上传POST /api/v1/uploads 使用 multipart，限额独立于 JSON。
密钥查询字符串里的 API key 不被接受。响应不回传密钥。
变更插件、MCP 配置和部分运行状态在进程启动时加载。管理接口保存安装状态，不代替重启。

鉴权与错误

配置了 server.api_keys 时，请求必须带下列之一：

X-API-Key: <key>
Authorization: Bearer <key>

未配置密钥时，只有本机回环连接、回环 Host、同源或缺失的 Origin，且没有转发头，才允许无密钥访问。同机反向代理也要配置密钥。GET/HEAD /、/api/v1/health/live 和 /api/v1/health/ready 公开；/api/v1/health/detail 走普通鉴权。

lh qr 签发的临时 key 只存在于进程内存，默认 24 小时，API 重启后失效，不写入 config.json。

错误体

{
  "error": "message",
  "code": 400,
  "error_code": "invalid_request",
  "request_id": "server-generated-id",
  "details": "optional details"
}
状态含义
401 / 403缺少密钥 / 密钥无效
404 / 405 / 409不存在 / 方法不允许 / 冲突
413 / 415 / 429请求体过大 / 媒体类型不支持 / 超过配额，429 带 Retry-After: 60
500 / 503内部错误 / 服务未初始化

聊天

POST /api/v1/chat

SSE 流式对话。省略 session_id 会新建会话；显式传入但不存在的会话在调用模型前返回 404。max_iterations 取 0 到 300，0 表示使用配置默认值。

curl -N http://127.0.0.1:9090/api/v1/chat \
  -H 'Content-Type: application/json' \
  -d '{"message":"hello"}'

事件保留类型和内容，并带 run_id、event_id 和 SSE id:。失败事件含字符串 error、error_code 和 status: "failed"，后面不再跟成功的 complete。取消为 type: "cancelled"。这个端点不重放持久游标；可重试投递使用 WebSocket。

POST /api/v1/chat/sync

同步返回整包。请求字段与流式接口相同。成功响应使用实际保存消息的会话。

{
  "response": "assistant response",
  "session_id": "session-id",
  "iterations": 1,
  "tokens_used": 0,
  "tool_calls": [],
  "duration": "1.2s"
}

会话

方法路径说明
GET/api/v1/sessions列表。查询参数 q、limit、offset。条目含 format、byte_size、pinned、project。
POST/api/v1/sessions创建会话。
GET/api/v1/sessions/{id}读取会话。带 limit 时从最新消息向前分页，offset 是从末尾跳过的条数。
PATCH/api/v1/sessions/{id}至少提供一个字段：title、pinned、project。只写元数据。
DELETE/api/v1/sessions/{id}删除会话并取消该会话的在途任务。
GET/api/v1/sessions/{id}/tools分页工具轨迹。每条含 duration_ms、status、success。汇总含调用数、成功、失败、进行中和成功率。
GET/api/v1/sessions/{id}/backups列出会话备份。
POST/api/v1/sessions/{id}/backups/{backup}/restore恢复指定备份。
POST/api/v1/sessions/{id}/compact压缩会话。可选 force_local、dry_run。
GET/api/v1/sessions/{id}/compact/latest最近一次压缩记录。没有记录时 404。

工具轨迹的 turn=first 只在原始首轮仍在时有效。压缩边界已经盖住原始轮次时返回 410，不会把后续对话标成第一次执行。没有写入 duration_ms 的旧消息读出来是 0。

命令与插件

方法路径说明
GET/api/v1/commands返回 commands 和 count。插件命令的 group 为 plugins，名称保持 plugin:command。
POST/api/v1/commands执行目录中的命令。插件命令可带或不带前导斜杠。省略会话会新建；传入的会话必须存在。
GET POST/api/v1/plugins列出或安装。安装体包含 source，可选 ref、subdir、trust。
GET DELETE/api/v1/plugins/{name}读取或移除登记。不可变缓存保留。
POST/api/v1/plugins/{name}/enable保存启用状态。
POST/api/v1/plugins/{name}/disable保存停用状态。
POST/api/v1/plugins/{name}/update按已记录来源更新。

插件命令成功时 HTTP 200 且 ok: true。循环失败仍可能是 HTTP 200、 ok: false，客户端必须看 ok。安装、启停和更新不执行插件，也不重启进程；正在运行的 Agent 继续使用启动时的快照。

模型与配置

方法路径说明
GET/api/v1/models模型列表。可选 kind、provider、refresh=1。
GET PUT/api/v1/models/effort读取或设置推理力度。稳定选项为 auto、none、minimal、low、medium、high、xhigh。
POST/api/v1/models/switch切换模型。体为 kind、model，可选 provider。
GET POST/api/v1/models/profiles列出或应用模型配置档。应用体为 {"name":"..."}。
GET/api/v1/config脱敏配置。响应带配置版本 ETag。
PUT/api/v1/config完整替换。被打码的密钥会保留原值。
PATCH/api/v1/config局部修改。
GET/api/v1/config/schema字段类型、默认值和重启提示。敏感默认值保持 null。
POST/api/v1/config/reload重新加载。无效配置被拒绝，原配置继续生效。

工具、技能、MCP

方法路径说明
GET/api/v1/tools当前可用工具。
GET/api/v1/skills技能列表。
GET DELETE/api/v1/skills/{name}详情或卸载。
POST/api/v1/skills/{name}/enable启用。状态机拒绝时返回 409。
POST/api/v1/skills/{name}/disable停用。
POST/api/v1/skills/{name}/reload重载一个技能。
POST/api/v1/skills/reload重载全部技能。

GET POST/api/v1/mcp/servers查看状态，或对已配置名称执行 connect、refresh、disconnect。传输和进程参数仍在配置里。

技能子路径还有 uninstall、rollback、versions 和 installs。未知子资源返回 404。MCP 未知动作返回 400，连接失败返回 502。

WebSocket 与 gRPC

GET /api/v1/ws

升级为 WebSocket。鉴权头与 HTTP 相同。

ws://127.0.0.1:9090/api/v1/ws?session=<session-id>
  • 同一会话、同一请求 ID 和同一输入会复用已接受的运行，不重复执行。
  • 同一 ID 但输入不同，返回 REQUEST_CONFLICT。
  • 初始持久化失败返回 PERSIST_FAILED，不会排队。
  • 重连发送 type: "reconnect"，data.last_message_id 填最后实际收到的事件。客户端也要按 event_id 去重。
  • type: "lucky" 先收集同一会话的多条消息，off 时合并成一轮。收集状态只在当前进程内存里。
  • 任务入库后向所有连接推送 type: "task_event"。

GET /api/v1/ws/stats

当前 WebSocket Hub 统计。

lh serve 不监听 gRPC。嵌入方使用 luckyagent-app/api/grpc 的 NewGRPCServer。聊天走真实会话；max_iterations 同样是 0 到 300。非空 metadata 会被拒绝，因为它没有定义语义。

健康检查、网关与协作

方法路径说明
GET/api/v1/health/live存活。公开。
GET/api/v1/health/ready就绪。公开。
GET/api/v1/health/detail详细健康，需要普通鉴权。
GET/api/v1/metrics指标快照。
GET/api/v1/stats服务统计。
GET/api/v1/proactive/status主动运行状态。可选 limit。
GET/api/v1/soul当前人格。 name 来自身份行，system_prompt 是全文。
GET/api/v1/gateways网关列表。
POST/api/v1/gateways/{name}/start在 lh serve 进程内启动网关。已运行时 409。不要同时再跑 lh msg-gateway start。
GET/api/v1/agents协作注册表。
POST/api/v1/agents/delegateHTTP 委派。它和模型工具 delegate_task 的任务视图没有完全打通。

协作还有 register、deregister、task、tasks、cancel、blackboard、messages。工作流入口是 /api/v1/workflows 和 /api/v1/workflow-instances。嵌入器入口是 /api/v1/embedders、/register、/switch 和按名称的子路径。人格模板在 /api/v1/soul/templates。

pprof 不属于 /api/v1。只有设置 LA_PPROF_ADDR 后才在该地址提供 /debug/pprof/。
